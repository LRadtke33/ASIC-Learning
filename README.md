# ASIC Learning

A hands-on ASIC design course built around the open-source **SkyWater SKY130** PDK
(`sky130_fd_sc_hd` standard cells) and open tools (Yosys, OpenROAD/OpenSTA, LibreLane,
Magic, KLayout, Netgen, ngspice).

**84 lessons and 7 labs** run from device physics and standard cells through timing,
low power, verification, test, placement and routing, physical signoff, Caravel
integration, tapeout and post-silicon bring-up, plus analog and mixed-signal topics.

## View the course

- Online: https://lradtke33.github.io/ASIC-Learning/
- Offline: clone or download this repo and open `index.html` in a browser. No server is needed.

## Contents

- `index.html`: the course home and the full lesson list
- `*.html`: the lessons
- `labs/`: lab material and recorded tool runs (`labs/analysis_examples/`)
- `glossary.html`: the glossary
- `README.txt`: detailed course notes, sources and changelog

Numbers marked as recorded come from actual tool runs on SKY130. Teaching estimates are
labelled as such. Bundled third-party images are credited in `README.txt`.
