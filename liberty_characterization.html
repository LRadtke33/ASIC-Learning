Standard-Cell Characterization: How Liberty Is Made

A Liberty table is a measured grid: input slew versus output load, delay at 50 %, slew at 20–80 %, and, for a sequential cell, a constraint found by searching. The SKY130 HD file you already read was built this way.

Where the facts come from. The 50 % delay and 20–80 % slew thresholds are those already verified in the bundled HD Liberty (lesson 23). Lab 1 compares a schematic inv_1 against that archived table. The setup-region clk-to-Q stretch on dfxtp_1 in lesson 20 is a related measurement (a pushout curve), not a full official setup characterisation. This lesson walks through how a 7×7 NLDM table and a setup bisection are produced. It does not publish a new 7×7 table or a new Liberty file.

What you will learn

  • Describe a slew×load delay sweep in ngspice, and the 50 % / 20–80 % thresholds this library uses.
  • Say how a setup time is found by bisection, and how that differs from a single clk-to-Q delay.
  • Distinguish NLDM, CCS and LVF, and what a power table is recording.

1. A delay table is a sweep

For a combinational arc the characterisation bench is: drive the input with a defined 20–80 % ramp, load the output, measure the 50 %–50 % delay and the output 20–80 % slew, and repeat on a grid. This library’s header uses exactly those thresholds (lesson 23). Lab 1 is the student version of a point on that grid. A production library fills every index, at every corner, with extracted parasitics. Lesson 29’s schematic FO4 of 72.15 ps is a different bench, not a Liberty extraction.

2. A setup time is a search, not one delay

Setup and hold are constraints: the smallest D–CLK offset at which CLK→Q still meets a chosen criterion (for example a limit on clk-to-Q pushout). The loop bisects that offset. Lesson 20’s recorded pushout on dfxtp_1 is the physics: clk-to-Q is flat at 168.97 ps from −400 to −150 ps, 169.16 ps at the Liberty setup of −103 ps, and stretches through 211 ps at −30 ps. The Liberty 0.103 ns is the library’s own criterion under its own conditions; that curve does not replace it.

Check your understanding — why not call setup “the offset where Q stops toggling”?

Q can still toggle and be late: a stretched clk-to-Q can miss the next stage. The library picks a quantitative criterion. Different criteria give different numbers, which is why lesson 20 refused to overwrite 0.103 ns with a single point from its curve.

3. Power tables, and NLDM versus CCS versus LVF

Power tables record internal energy against a slew/load index, with leakage often state-dependent. Lesson 38 uses those tables; it does not make them. NLDM stores a delay and a slew at each grid point — what this HD file is. CCS stores a current waveform, which composes better through interconnect. LVF adds statistical moments for variation-aware STA. This lesson does not claim CCS or LVF tables for the bundled file.

Check your understanding — a schematic FO4 disagrees with Liberty by 10 %. Is the library wrong?

Not necessarily. Liberty includes extracted parasitics and a specified waveform, at a stated corner. A schematic FO4 is a different bench. Lab 1 exists to make the comparison at matching conditions.

Key takeaways

  • Combinational Liberty is a slew×load sweep at this file’s 50 % / 20–80 % thresholds.
  • Setup and hold are bisections. Lesson 20’s pushout curve shows the shape for dfxtp_1; it is not a new Liberty number.
  • The bundled HD file is NLDM. This lesson did not write a new table.
