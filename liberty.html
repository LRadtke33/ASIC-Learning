Liberty Files: What a Cell Library Records

The text file that records how a standard cell behaves — its function, pin capacitance, timing arcs and power — at one process corner, so that a timer can look up a delay instead of simulating transistors.

Where the numbers come from. The cell throughout is sky130_fd_sc_hd__inv_1 at the typical corner tt_025C_1v80: 25°C, 1.80 V. Time in the file is nanoseconds. Capacitance is picofarads.

What you will learn

  • Find a cell’s function, pin capacitance and timing arcs in a Liberty file.
  • Explain why each process, voltage and temperature corner is a separate Liberty file.
  • Name the extra arc types a flip-flop adds, and what Liberty leaves to analog simulation.

1. One cell is described three ways

Placement and routing use a LEF abstract rather than every layout polygon. Synthesis and timing use Liberty. Transistor simulation uses a SPICE netlist plus device models, and physical verification uses the actual layout. Library characterization normally includes the cell’s internal parasitics; the exact characterization deck and extraction procedure must be established from the library release, not inferred from a schematic-only netlist.

  • The LEF abstract is the shape: how wide the cell is, where the pins sit, which tracks are blocked. The placer and the router use it.
  • The Liberty file is the behavior: what the pin does, how much capacitance it has, and how long the output takes. Synthesis and the timer use it.
  • The SPICE netlist is the transistors. That is what was simulated to produce the Liberty tables. Analog work stays here. The timer does not.

In the open SKY130 flow. The library team produces Liberty files by characterization: a tool simulates each cell in SPICE over a grid of input slews and output loads at each corner and writes the results as tables. Commercial characterizers are Cadence Liberate and Synopsys SiliconSmart; CharLib is an open-source one. As a designer you read these files — Yosys, OpenROAD and OpenSTA all load them — rather than write them.

2. What you find inside the cell

A Liberty library is a nest of blocks. The library names the corner and the units. Each cell names its pins. Each output pin has a function and a timing block. For this inverter the function is (!A): Y is the opposite of A.

The timing block identifies the causing input with related_pin. This library uses delay_model : table_lookup: an NLDM (nonlinear delay model) grid of characterized delay and transition values. A timer interpolates within that grid; other Liberty models, including CCS (composite current source), use richer waveform descriptions. [Sources]

pin (A) {
  direction : input;
  capacitance : 0.002302;       /* pF, 2.30 fF */
  rise_capacitance : 0.002390;
  fall_capacitance : 0.002214;
  max_transition : 1.5;          /* ns */
}
pin (Y) {
  direction : output;
  function : "(!A)";
  max_capacitance : 0.181284;    /* pF */
  timing () {
    related_pin : "A";
    timing_sense : negative_unate;
    timing_type : combinational;
    /* cell_rise table lives here */
  }
}

The library header, shared by every cell, fixes how to read every number:

  • time_unit : 1ns, capacitive_load_unit (1, pf), voltage_unit : 1V, leakage_power_unit : 1nW.
  • Delay is measured from the moment the input crosses 50% of VDD to the moment the output crosses 50%. At 1.80 V those points are both 0.90 V.
  • Slew, called transition in the file, is the time from 20% to 80% (0.36 V to 1.44 V). slew_derate_from_library is 1.0, so the stored number is that 20–80 time, not a stretched 0–100 time.
  • timing_sense : negative_unate means the output moves the opposite way from the input. A buffer is positive_unate. A gate that can go either way, such as an XOR, is non_unate.

The cell also has supply pins VPWR and VGND, and body pins VNB and VPB. In the SPICE netlist the NMOS body is VNB and the PMOS body is VPB. At this corner both wells sit at the rails: VPWR and VPB are 1.8 V, VGND and VNB are 0. A digital timer treats them as the supplies. An analog reader recognizes the fourth terminal of each MOSFET.

Leakage is stored per input state, in nanowatts. With A high the cell leaks 0.01046 nW. With A low it leaks 0.000196 nW. The cell attribute cell_leakage_power : 0.005327 is the average of those two. The same indexes used for delay also hold an energy table (rise_power, fall_power). switching_power_split_model is true, so the energy stored on the load capacitor is split out of the cell's own number, and some of those entries are negative.

3. A corner is another copy of the same file

A cell name identifies the cell; the library name identifies its characterization condition. sky130_fd_sc_hd__tt_025C_1v80 means typical process, 25°C and 1.80 V. ss_100C_1v60 and ff_n40C_1v95 are familiar slow and fast examples, but the project configuration determines which corners are required. The four files compared below are explicitly named; the comparison does not claim a complete signoff corner set.

Same question at every corner: input edge 0.01 ns, load 9.21 fF, straight line between the two neighboring load columns. These are four files that actually ship as plain tables. ff_n40C_1v95, a commonly used fast-corner name, is not one of the four.

The slow file is slower on both edges. The two fast files disagree about which edge they win. The higher voltage, even at 100°C, wins the rise (the high-Vt PMOS cares a lot about gate voltage). The colder file wins the fall. "The fast corner" is not one speed. It is whichever file you opened, and each arc inside it has its own number.

The files record default_arc_mode as worst_edges or best_edges. This is a user-defined attribute in the published header, not a portable instruction to the timing engine to select its analysis corner. Select the intended early/late libraries, operating conditions and derating in the timing flow. The stored tables already contain the characterized result.

4. A flip-flop has more arc types than an inverter

The inverter arcs in this lesson are combinational: cell_rise and cell_fall for delay, rise_transition and fall_transition for the output edge. A flip-flop adds arcs that are checks, and one arc that is the clock.

rising_edge is clock to Q. setup_rising and hold_rising are the two checks on D against that same edge. min_pulse_width is a check on the clock pin alone. timing_sense on Q is non_unate, because Q rises or falls with D. The inverter stays negative_unate. The numbers for those flop arcs are lesson 26 and lesson 25.

5. The analog–digital handoff

An analog designer should provide a realistic input edge, supply range and output load. A digital designer should return the actual clock, activity and routed capacitance. A clean 0/1 functional simulation has none of that information. Pin capacitance is an abstraction of nonlinear charge, and an NLDM lookup does not by itself model arbitrary supply droop, crosstalk or a waveform with ringing.

Check your understanding — you must check hold at the fast corner. Can the timer reuse the typical Liberty file at a higher voltage?

No. Each corner is a separate file, characterized at its own process, voltage and temperature. Load the fast-corner file the flow specifies — ff_n40C_1v76 in this library — and check that its name and conditions match the corner you intend to sign off.

Check your understanding — does the Liberty file tell you where pin A of inv_1 is?

No. Liberty describes behavior: function, pin capacitance, timing and power. The pin shapes and the cell outline are in the LEF, and the transistors are in the SPICE netlist.

Key takeaways

  • Liberty is the behavior view of a cell: function, pin capacitance, and timing tables. LEF is the shape. SPICE is a circuit view; characterization may also include internal extracted parasitics and a specific measurement setup.
  • Units for this library: nanoseconds, picofarads, volts, nanowatts of leakage. Delay is 50% to 50%. Slew is 20% to 80%, and slew_derate_from_library is 1.0.
  • A corner is a separate library file. The slow file used here is ss_100C_1v60. A fast file is not automatically faster on every edge.
  • A flop adds rising_edge, setup_rising, hold_rising, and min_pulse_width. Its Q pin is non_unate.
