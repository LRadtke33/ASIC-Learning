Seven Practical ASIC Design Labs

Use the same circuit idea across waveforms, models, layout estimates, and digital protocols.

What you will learn
  • Start from a prediction, inspect the exact model, and run a reproducible experiment.
  • Keep observed results separate from hypothetical extensions.
  • Carry a requirement across analog, digital, and physical views.

The seven labs are designed to follow the illustrated lessons. Every lab includes a detailed walkthrough, diagrams, tables, actual recorded results, source files, and solved checks. You can read everything offline; installed tools are needed only to rerun experiments. The supplied model subset and synthesis reference are local, so default runs need no network after setup.

Run the course experiments

From the extracted learning folder, after installing the prerequisites:

python labs/run_all.py
# Include the separate SKY130 synthesis/equivalence example:
python labs/run_all.py --include-synthesis
# Choose only selected experiments:
python labs/run_all.py --labs 1 3 analysis

Each default runner writes a separate run_results/ directory. The included results/ directories preserve the recorded evidence. Read the individual README before changing output paths. The master runner stops on a failed command and saves its execution report.

What to hand in after each lab

State the question, make a numerical prediction, list the model and conditions, show the measurement definition, report the observed result, and explain a discrepancy. Attach the deck or RTL revision and relevant raw data. Identify the next experiment needed for a physical implementation claim. A passing simulation is valuable evidence when its scope is explicit.

Why is a deliberately failing test included in Lab 5?

A checker that never fails might be disconnected or incomplete. The negative control modifies an isolated copy to violate the mailbox data-hold contract. The expected assertion failure demonstrates that this specific fault is observed; it does not prove complete verification coverage.
