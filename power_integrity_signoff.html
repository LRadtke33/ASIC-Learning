Power-Integrity Signoff: Static IR, Dynamic IR & EM

On the Lab 6 45% SPM, OpenROAD’s static analyze_power_grid at nom_tt reports a worst VPWR drop of 132 µV and a worst VGND rise of 100 µV, on a 1.28 mW, 1.80 V rail. The numbers are small because the die is small; they are measured, not invented.

Where the facts come from. LibreLane Classic 3.0.17’s OpenROAD.IRDropReport and irdrop.tcl were read from the local install. The Lab 6 45% SPM run RUN_2026-11-11_16-09-06 had RUN_IRDROP_REPORT: true but the step was not executed at the time (signoff resumed at Magic.StreamOut). On 11 November 2026, America/Chicago, this course ran OpenROAD dcf36133 — the same binary LibreLane 3.0.17 uses here — on that run’s final/odb/spm.odb and final/spef/nom/spm.nom.spef, with the HD tt_025C_1v80 Liberty and the run’s SDC, set_pdnsim_net_voltage 1.80 V on VPWR and 0 V on VGND, and analyze_power_grid -enable_em. There is no VSRC_LOC_FILES, matching Lab 6’s resolved config; voltage sources are OpenROAD’s default placement. No VCD and no activity override (vectorless, Liberty+SDC). The reported 1.28 mW agrees with the Lab 6 STA report_power of 1.275 mW at the same corner. Decks, CSVs, EM files and the map are in labs/analysis_examples/irdrop/. The static-versus-dynamic waveform and the strap-resistance worked example remain teaching figures. This is a block-level static result, not a package-aware dynamic signoff.

What you will learn

  • Say what LibreLane’s OpenROAD.IRDropReport actually runs, and what this lesson added (-enable_em) or still did not run (dynamic, vector-based IR).
  • Distinguish static from dynamic IR, and vectorless from vector-based current.
  • Use strap pitch, strap width, and decap as knobs, without treating a teaching table as a measured drop.
  • Connect a voltage drop to timing: a 10% supply collapse is not a 10% delay increase by a universal law, but it is not free either.

1. What LibreLane actually invokes

In Classic 3.0.17, OpenROAD.IRDropReport sits after OpenROAD.RCX and OpenROAD.STAPostPNR. It is gated by RUN_IRDROP_REPORT, which defaults to true and was true on Lab 6. The script librelane/scripts/openroad/irdrop.tcl does the following, in this order:

  1. Read the current OpenDB and the SPEF for the default corner.
  2. If VSRC_LOC_FILES is set, call analyze_power_grid -net $net -voltage_file … -vsrc $vsrc_file for each mapped net. If it is not set — and it was not, on the usual block-level run — the script warns (the step’s Python does the same: results “may [be] inaccurate” unless you are not integrating a top-level chip for manufacture), then for each VDD net sets set_pdnsim_net_voltage -net $net -voltage $::env(LIB_VOLTAGE) and calls analyze_power_grid -net $net -voltage_file …, and for each ground net sets 0 V and does the same.

That is a static IR analysis on the extracted grid. The shipped script does not pass OpenROAD’s -enable_em flag, does not attach a VCD or SAIF, and does not write a dynamic waveform. OpenROAD’s PSM can do more than this script asks; quoting analyze_power_grid -net VPWR -enable_em as “what LibreLane runs” would be wrong. If you want EM current-density checks or a vector-based dynamic analysis, that is an extra invocation you must add and then actually run.

The step parses the report for “Average IR drop” and “Worstcase IR drop” in volts. The original Lab 6 folder still has no IR step directory — the analysis on this page was run afterwards, on that run’s frozen final/ views, and is stored under labs/analysis_examples/irdrop/.

2. Static drop, dynamic drop, and where the current comes from

Static IR is Ohm’s law on a DC current distribution: each instance is given an average current, the grid is a resistive network (from SPEF or from the grid extraction), and the result is a single voltage at each node. It catches a thin strap, a missing via stack, a region far from a pad, and a systematically overloaded corner. It does not see a clock-edge surge.

Dynamic IR is the same grid with time-varying current, plus decap and, if you include them, package R and L. The voltage sags on a simultaneous-switching edge and recovers. A design can pass static IR and fail dynamic IR, which is the same distinction lesson 69 already made for the package. Decap cells (lesson 52) and on-die and on-board capacitors shrink the excursion; they do almost nothing to a DC drop.

Vectorless current is estimated from Liberty power, from a default (or set) activity, or from a statistical switching model — no simulation waveform required. Vector-based current comes from a VCD, SAIF, or similarly annotated vector: it is only as good as the vectors you trusted. A quiet testbench understates the surge; a pathological one overstates it. LibreLane’s shipped irdrop.tcl is in the first family: it has no hook for a vector file.

Check your understanding — you added decap and the static IR report barely moved. Did the step fail?

Not for that reason. Static IR uses average current and resistance. Decap is a capacitor; it does not change the DC solution except through the small leakage and the metal it occupies (which can even displace a strap). Look at a dynamic result, or at a scope, for the effect you wanted. If the static drop itself is too large, the knobs are wider or denser straps, more vias, closer taps to pads, and lower average current — not more decap.

4. Knobs: pitch, width, vias, and a LEF-based worked resistance

The HD nom tech LEF (the same file lesson 29 uses) gives met4 RPERSQ = 0.047 Ω/sq and a minimum width of 0.3 µm, and met5 RPERSQ = 0.0285 Ω/sq at 1.6 µm minimum. Those are sheet resistances, not a signed-off extraction.

Worked teaching calculation. A 200 µm run of minimum-width met4, used as a single strap with no other path, has

R = 0.047 × (200 / 0.3) = 31.3 Ω

At a uniform 10 mA (a round teaching current, not a Lab 6 number) the drop along that one strap is 313 mV — already severe on a 1.80 V rail. Doubling the width halves R to 15.7 Ω (157 mV). Halving the pitch, if it puts a second identical strap in parallel across the same current, halves it again. Real grids share current among many straps and vias; this arithmetic is to show the scale of the knobs, not to replace analyze_power_grid.

5. IR and timing, and EM on the same grid

A cell at 1.62 V on a 1.80 V rail is a 10% static collapse. Delay is a non-linear function of supply — lesson 29’s FO4 goes from 72.15 ps at 1.80 V to 92.33 ps at 1.60 V and 132.16 ps at 1.40 V, on the same models — so a 10% drop is not a 10% slowdown, and it is not free. Some timing flows derate or re-characterize at a reduced voltage to close IR-aware setup; that is a methodology choice, and this course has not run one. Dynamic IR is worse for a short window around the edge, which is also when the path is drawing current. Hold can be the surprise at a high supply with little drop on the launch clock and more drop on the capture clock, or the reverse.

Electromigration on the grid is a current-density check over the same metal, with time-average and RMS limits (the HD LEF cites Iavg and Irms at Tj = 90 °C — already in lesson 30). This lesson’s OpenROAD invocation passed -enable_em, which LibreLane’s Classic 3.0.17 irdrop.tcl does not. The report is a current, not a pass/fail against those limits: the largest element on VPWR carries 35.5 µA (a met1–met2 connection at (70.52, 40.80) µm), and on VGND 30.5 µA. For comparison only, a minimum-width met1 rail’s LEF Iavg limit is 2.8 mA/µm × 0.14 µm = 392 µA; the recorded max is an order of magnitude smaller, and that comparison is not a via-EM signoff, because the max elements leave met1 into met2.

Check your understanding — is a 50 mV static drop “safe” because it is less than 5% of 1.80 V?

It is a smaller problem than 300 mV, but “5%” is not a universal limit. What matters is the delay at the actual voltage, at the actual corner, on the actual path, plus the dynamic dip and the EM density on the metals that carry the current. A 50 mV drop that is also a 50 mV mismatch between two clock branches is a hold or skew issue, not just a percentage of VDD.

Key takeaways

  • LibreLane Classic 3.0.17’s OpenROAD.IRDropReport is a static, SPEF-based analyze_power_grid on VDD and ground, optionally with VSRC_LOC_FILES. It does not pass -enable_em and does not run a vector-based dynamic analysis.
  • Lab 6 had the flag on and originally produced no report (resume at Magic.StreamOut). A later OpenROAD run on that final/ measured 132 µV worst VPWR drop and 100 µV worst VGND rise, at 1.28 mW. The map is that CSV. This is a small block with default voltage sources, static and vectorless.
  • Static IR is DC; dynamic IR is the sag; decap helps the second, not the first. Vectorless current is an estimate; vector-based current is only as good as the vectors.
  • Pitch, width, upper layers, vias, and pad locations are the DC knobs. Sheet-resistance arithmetic from the HD LEF (a 200 µm min-width met4 strap at 10 mA would drop 313 mV) shows the scale on a larger current or a thinner path; it is not this SPM’s measured 132 µV.
