ADC & DAC Interfaces

From a physical voltage and sample time to a meaningful digital word.

What you will learn

  • Separate resolution, accuracy, linearity, noise, and effective number of bits.
  • Budget acquisition settling and reference disturbances at an analog/digital interface.
  • Connect sampled analog values to coherent digital transfer and physical implementation.

Why it matters
Converters are where a voltage becomes a number, and where an error becomes permanent.

1. A converter is an interface contract

An analog-to-digital converter (ADC) assigns a digital code to an analog input measured at a particular time. A digital-to-analog converter (DAC) creates an analog output associated with a code. The number of bits describes the code space; it does not guarantee that the analog input, reference, clock, switches, or output driver can support that accuracy.

We will use a hypothetical 10-bit converter with a 1.8 V input span to connect the ideas to the 1.8 V SKY130 device context. This is an arithmetic example, not an existing SKY130 ADC or DAC specification. Real input common-mode range, reference range, rail headroom, input protection, and device reliability must come from the chosen circuit and validated models. A nominal 1.8 V supply does not by itself permit a 0–1.8 V accurate analog input.

2. Code size and quantization

For a uniformly spaced ideal N-bit converter with full input span Vspan, the nominal least-significant-bit step is q = Vspan/2N. Our example has 1,024 codes and q = 1.7578125 mV. Codes run from 0 to 1,023. An ideal unipolar DAC convention Vout = code · q therefore puts the highest code at 1.798242 V, one step below 1.8 V. A device data sheet may define endpoints or gain differently.

For an ideal nearest-level ADC model away from clipping, the quantization error is bounded by ±q/2. If that error is uniformly distributed and sufficiently uncorrelated with the input, its RMS value is q/√12, or 0.5074 mV RMS here. The statistical model can fail for constant inputs and coherent tones; quantization error can be correlated and create spurs. Saturation outside the input range is not bounded by ±q/2. These assumptions are developed in ADI MT-001.

3. Resolution, SNR, and ENOB answer different questions

For an ideal full-scale sine wave, the uniform quantization-noise model integrated over the whole Nyquist band gives SNR ≈ 6.02N + 1.76 dB. At 10 bits, this is approximately 61.96 dB. Reducing the signal amplitude lowers the signal-to-quantization-noise ratio; oversampling and filtering change the bandwidth in which noise is measured. See MT-001 and the sampling and aliasing lesson.

For a measured full-scale sine, a commonly reported dynamic effective number of bits is ENOB = (SINAD − 1.76)/6.02. SINAD includes noise and distortion; SNR conventionally excludes harmonics from its noise sum. A measured 56 dB SINAD corresponds to about 9.01 ENOB. The input frequency, amplitude, sample rate, and measurement bandwidth matter. ENOB does not establish DC offset, absolute gain accuracy, or monotonicity. See ADI MT-003.

4. Acquisition time belongs in the timing budget

A switched-capacitor ADC input draws charge when its sampling switch closes. The previous sample, source resistance, switch resistance, driver impedance, and sampling capacitance determine how closely the held voltage approaches the desired input. A high input resistance quoted at DC does not describe that transient load.

Worked first-order example: assume an effective source-plus-switch resistance of 2 kΩ and a 5 pF sample capacitor. Then τ = RC = 10 ns. After a full-span step, the remaining error is Vspanexp(−t/τ). To make acquisition error smaller than half of a 10-bit LSB:

Real inputs often have a second-order response because a filter capacitor and the ADC sampling capacitor interact. Slew rate, finite amplifier bandwidth, nonlinear switch resistance, charge injection, and sample kickback can dominate. The TI acquisition-time application report SBAA173A derives a more detailed model. Simulate the actual drive network and extracted parasitics; a one-pole equation is a useful estimate, not a complete acceptance test.

5. The reference is a signal

An ideal converter compares the input with its reference. Reference noise and droop therefore alter conversion thresholds or output steps. A SAR (successive-approximation register) converter's internal switching can produce short reference-current pulses even when the average current looks modest. The reference buffer, decoupling, routing impedance, and return path must handle the transient.

Charge-budget example: assume a conversion transient removes 10 pC from a local 22 nF reference capacitor before its source replenishes it. The ideal droop is ΔV = Q/C = 0.4545 mV, about 0.259 of our example LSB. This ignores ESR, ESL, voltage-dependent capacitance, routing, and buffer dynamics. It is a sizing check, not a guarantee; the charge value is assumed, not a SKY130 specification.

Supply and ground disturbance can affect both the reference and the input driver. A quiet-looking reference node measured against a moving local ground may still yield a wrong input-referred result. Connect this to return paths and coupling and noise and mismatch.

6. Nonidealities and an honest error budget

For an ADC, DNL = actual code width / q − 1. A zero-width, missing code corresponds to DNL = −1 LSB under this definition. For a DAC, the analogous DNL uses the output step; a negative step corresponds to DNL below −1 LSB and violates monotonicity. INL depends on whether the reference line is endpoint fitted or best fitted, so compare specifications using the same definition. The ADI converter test guide AN-835 discusses measurement conventions.

Separate deterministic errors from random noise. For example, assume residual offset up to 0.30 LSB, gain contribution up to 0.20 LSB at the input of interest, INL up to 0.40 LSB, and settling up to 0.10 LSB. A conservative same-sign sum is 1.00 LSB before quantization. This demonstrates that small individual specifications can exceed an overall target. Avoid counting the same error twice if a quoted total-error specification already includes its components.

If independent RMS input-referred analog noise sources contribute 0.20 and 0.15 LSB over the same bandwidth, their combined RMS noise is 0.25 LSB. Only when the uniform, uncorrelated quantization model is justified may its 1/√12 LSB RMS term be combined in quadrature too, giving about 0.382 LSB RMS. Fixed worst-case bounds do not belong in that RMS calculation. Correlated sources require covariance information.

The SKY130 device documentation describes the available devices; it does not validate a converter architecture by itself.

For a DAC, check output load, settling time, glitch impulse during multi-bit transitions, and reconstruction filtering. A large transition such as 0111111111 → 1000000000 can switch many elements even though the desired output changes by only one LSB. The digital bus can be correct while the analog output is temporarily wrong.

For an ADC, transfer the code and its validity coherently. If the receiving logic uses a different clock, use a handshake or asynchronous FIFO; independent synchronizers on every data bit do not preserve a word. Track acquisition time separately from result latency and delivery time. See CDC and reset and mixed-signal verification.

8. Solved checkpoint

A 10-bit, 1.8 V-span input settles for 50 ns with τ = 10 ns. Is it within half an LSB after a full-span step?

No. The remaining error is 1.8·exp(−5) = 12.13 mV. One LSB is 1.7578 mV, so the error is about 6.90 LSB. More than 76.25 ns is required for the ideal first-order error to fall below half an LSB. Extra margin is still needed for other error sources and for limitations of the model. Increasing the number of output bits without changing the acquisition interval makes the error larger when expressed in LSB.

Check your understanding — a 12-bit ADC spans 0 to 1.8 V. What is one LSB, and what is the ideal SNR for a full-scale sine?

LSB = 1.8 V / 4096 ≈ 439.5 µV. Ideal SNR = 6.02 × 12 + 1.76 ≈ 74.0 dB. Real converters fall short of that because of noise, distortion and jitter.

Key takeaways

  • Bits describe levels; accuracy depends on input drive, reference, timing, noise, and linearity.
  • State the assumptions behind quantization-noise and ideal-SNR equations.
  • ENOB is a dynamic measurement under defined conditions, not a universal DC accuracy claim.
  • Budget acquisition and reference transients with the physical circuit and actual sample sequence.
  • Deliver complete words with a protocol that preserves their association with sample time and validity.
