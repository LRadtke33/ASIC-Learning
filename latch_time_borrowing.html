Latch-Based Design & Time Borrowing

A latch is transparent while its gate is open. That window lets a late path finish in the next half-cycle — time borrowing — and it changes the STA checks you have to write.

Where the numbers come from. Three HD latch cells were read from the local sky130_fd_sc_hd.lef: dlxtp_1 is 5.520 × 2.720 µm (12 sites), with pins D, GATE, Q; dlrtp_1 is 5.980 × 2.720 µm (13 sites), a resettable latch; dlxbn_1 is 6.900 × 2.720 µm (15 sites), with an active-low GATE_N. The HD flop dfxtp_1 is 7.360 × 2.720 µm (16 sites), already in lesson 20. DFFRAM’s latch-based configurations are described in lesson 43; this course has not re-run that generator. Timing-borrowing figures are teaching diagrams, not an STA run on a latch netlist.

What you will learn

  • Contrast a latch with a flip-flop, including two-phase and pulsed-gate use.
  • Draw a time-borrowing window and say what happens if a path is late into a transparent latch.
  • Name the STA checks a latch requires, and point at the HD latch cells and DFFRAM.

1. A latch is open for a level, not an edge

While GATE is true, dlxtp is transparent: Q follows D. When GATE falls, the value is held. A flip-flop is two latches of opposite phase (lesson 20, lesson 12): the slave is open only after the master has shut, so the path is sampled on an edge. Two-phase latch design makes that overlap explicit — φ1 and φ2, non-overlapping — so a path can leave a φ1 latch and arrive at a φ2 latch. A pulsed latch opens for a short pulse derived from the edge, and behaves almost like a flop if the pulse is narrow, or borrows if the pulse is wide.

The HD library’s dlxtp_1 (positive GATE, 5.520 µm wide) is smaller than dfxtp_1 (7.360 µm) by four site steps, as a single latch should be. dlrtp_1 adds a reset and three more sites. dlxbn_1 uses GATE_N and is 15 sites — the opposite phase, with a complementary output in the usual naming. These are LEF sizes, not a timing comparison.

2. What STA has to check

Flip-flop STA is a setup and a hold to an edge (lesson 26). Latch STA adds:

  • Data setup to the closing edge of the receiving latch — or, with borrowing allowed, a check that the path plus the borrowed amount still meets the next closing edge (a “time-borrow” budget).
  • Hold to the opening edge, so a short path cannot race through two open latches.
  • Pulse width and phase overlap, for pulsed and two-phase sets: a pulse that is too narrow fails to write; phases that overlap can create a race.
  • A borrow that is not infinite: some tools cap how much you may take from the next stage.

If you treat a latch as a flop in the SDC, you will both miss borrowing (and think a late path is a fail) and miss a hold-through that is real. The safer first design, and the one this course’s digital labs use, is edge-triggered HD flops. Latches are a deliberate choice, common in some datapaths and in latch-based DFFRAM configurations (lesson 43), and they need their own checks.

Check your understanding — a path is 60 ps late to a rising-edge flop. The same path, into a latch that stays open for 200 ps after that edge, is late by 60 ps. Does it fail?

Not on setup, if the latch is already open and the remaining 140 ps of transparency are enough for D to write, and if that 60 ps is then deducted from the next stage’s budget. It can still fail hold, or fail the next closing-edge check if the following path was tight. “Late to the edge” is not automatically “fail” for a transparent latch, which is exactly why the STA has to be told it is a latch.

Check your understanding — is dlxtp_1 a smaller flop?

No. It is a single transparent latch, 12 sites versus dfxtp_1’s 16. A flop is two latches. Using one dlxtp_1 where you meant a flop will be transparent for half the cycle and will not hold through that half.

Key takeaways

  • A latch is level-sensitive; a flop is two opposite-phase latches. HD dlxtp_1 / dlrtp_1 / dlxbn_1 are 12, 13 and 15 sites; dfxtp_1 is 16.
  • Time borrowing lets a path finish in the next open window, and owes that time back. STA must check closing-edge setup, opening-edge hold, and pulse/overlap.
  • DFFRAM can be latch-based on SKY130; this course has not generated one (lesson 43).
